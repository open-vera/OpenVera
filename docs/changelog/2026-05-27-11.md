### Changes

- **SK1 SkillAutoExtractor**: Extracts reusable skill templates from successful execution traces. Analyzes tool call patterns, infers domain/level triggers, and generates `Skill` definitions with system fragments. Supports batch extraction with deduplication.

- **SK2 SkillAutoScorer**: Scores skill effectiveness after execution using a composite metric: success rate (40%), speed (30%), cost efficiency (30%). Tracks execution records over time and provides ranked score lists.

- **SK3 SkillRecommender**: Recommends skills for tasks based on domain matching, keyword overlap (Jaccard similarity), and historical effectiveness from SkillAutoScorer. Supports explicit skill requests and configurable relevance thresholds.

- **SK4 SkillVersionManager**: Tracks skill definition changes with monotonic version numbers. Supports full version history, field-level diffs between versions, and rollback to any previous version (creates a new version entry for the rollback).

- **SK5 SkillHotReloader**: Watches skill directories for file changes using Node.js `fs.watch()`. Features debounced reload (300ms default), pin/unpin for protected skills, and event callbacks for reload notifications.

- **SK6 Tests**: 34 tests covering all new features — extraction criteria/batch/dedup, scoring composite/ranking/clear, recommendation domain/keyword/explicit/effectiveness integration, versioning diff/rollback/history, and more.
