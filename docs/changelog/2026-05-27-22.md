- `packages/core/src/channel/webhook-channel.ts` — WebhookChannelAdapter 类

  - 支持自定义 payload parser（WebhookPayloadParser 回调）
  - 可配置 path、methods、success status code、response body

## Phase 16 CH6：Channel Plugin Registry

### 变更

| Commit | 模块 | 内容 |
|--------|------|------|
| 311a792 | channel | ChannelPluginRegistry — 运行时动态加载/卸载 channel adapter |

### 实现要点

- `packages/core/src/channel/plugin-registry.ts` — ChannelPluginRegistry 类
  - `registerPlugin()` / `unregisterPlugin()` — 注册/注销 adapter 工厂（带元数据）
  - `loadAdapter()` / `unloadAdapter()` — 运行时动态创建/销毁 adapter 实例
  - `loadBatch()` — 批量加载多个实例
  - `unloadAllByPlugin()` — 按 plugin 卸载所有实例
  - `unloadAll()` — 卸载全部（自动 disconnect 已连接的）
  - `findByChannelType()` — 按 channel 类型查找插件
  - 4 种错误类：PluginAlreadyRegistered / PluginNotFound / AdapterAlreadyLoaded / AdapterNotLoaded
  - Plugin 元数据：name, description, channelType, version, author
  - LoadedAdapter 跟踪：pluginName, adapter, loadedAt, config
