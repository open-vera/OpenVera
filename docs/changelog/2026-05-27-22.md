### 实现要点

- `packages/core/src/channel/webhook-channel.ts` — WebhookChannelAdapter 类
  - HTTP server 监听 webhook POST 请求
  - 支持 4 种签名验证策略：GitHub (X-Hub-Signature-256)、Stripe (Stripe-Signature)、Slack (X-Slack-Signature)、Custom
  - HMAC-SHA256 + timingSafeEqual 防止时序攻击
  - 内置 payload parser：GitHub push/issue 事件、Stripe 支付事件
  - 支持自定义 payload parser（WebhookPayloadParser 回调）
  - 可配置 path、methods、success status code、response body
- `packages/core/src/channel/tests/webhook-channel.test.ts` — 49 tests
  - Lifecycle: 6 tests（状态转换、幂等 connect、disconnect 安全）
  - Webhook receiving: 11 tests（default parser 4 种字段名、senderId 提取、422/400/404 响应、CORS、计数）
  - Custom path/methods: 3 tests
  - GitHub signature: 3 tests（有效签名、无效签名、缺少 header）
  - Stripe signature: 2 tests（有效签名、无效签名）
  - Slack signature: 2 tests（有效签名、无效签名）
  - Custom signature: 3 tests（有效签名、自定义 prefix、无效签名）
  - GitHub parser: 3 tests（push/issue/unknown events）
  - Stripe parser: 1 test
  - Custom parser: 3 tests（自定义 parser、null 返回、headers 传递）
  - sendMessage: 2 tests（未连接抛错、outbound 记录）
  - onMessage: 1 test（unsubscribe）
  - getHistory: 2 tests（senderId 过滤、limit）
  - Custom response: 2 tests（自定义 status code、自定义 body）
  - Edge cases: 3 tests（默认 senderId、自定义 senderId、多 callback）
