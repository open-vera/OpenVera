## Changes

### SweBenchRunner (`packages/harness/src/eval/runners/swe-bench-runner.ts`)

- `SweBenchRunner` class — loads SWE-bench raw cases, converts to `EvalCase`, runs through `EvalHarness`
- Filter support: by difficulty (`easy/medium/hard`), by repository, by max cases
- Structured prompts: problem statement, repo, base commit, hints, version, environment setup
- Optional: include test patch and/or gold patch in prompt (for debugging)
- SWE-bench-specific metrics: `resolved` (pass rate), `patched` (non-empty patches), `patchAccuracy`
- Per-difficulty timeout: easy=120s, medium=300s, hard=600s
- Tags: `repo:<name>`, `difficulty:<level>`, `lang:<python|javascript>`

  - Report generation: statistics, level grouping
  - Metrics: resolved rate, patch rate, patch accuracy, empty results
