## Changes

### Phase 6: Session Manager (SS1-SS5)

- **SS1 Auto-compression**: `SessionManager.autoCompress()` triggers LLM-based compression when session token count exceeds threshold. Integrates with existing `compressMessages()` from context/compression.
- **SS2 Dedup & Merge**: `findSimilarSessions()` uses trigram Jaccard similarity on title/summary/firstPrompt. `mergeSessions()` marks duplicates with tags.
- **SS3 Keyword Index**: `buildIndex()` extracts keywords from session summaries. `searchByKeyword()` ranks by title/keyword/content relevance.
- **SS4 Lifecycle**: `cleanup()` removes sessions based on configurable TTL (days) and max sessions per project. Supports dry-run mode.
- **SS5 Tests**: 23 tests covering all features.
