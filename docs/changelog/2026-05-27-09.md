### Changes

**SQ1 — Storage Abstraction Layer** (`packages/core/src/storage/types.ts`)
- `StorageProvider` interface: CRUD, batch, query, transaction support
- `StorageValue` type: string, number, boolean, null, array, object
- `StorageEntry<T>`: value + metadata (createdAt, updatedAt, ttl, tags)
- `StorageQuery`: filter by tags, time range, key prefix/pattern, full-text search, pagination
- `StorageQueryResult`: entries + total + hasMore
- `StorageTransaction`: buffered ops with commit/rollback
- Domain types: `StoredSession`, `StoredMemory`, `UserDataEntry`
- Error hierarchy: `StorageError`, `StorageNotFoundError`, `StorageConflictError`, `StorageTransactionError`, `StorageBackendError`
- `StorageOptions`: backend type, dbPath, storeDir, WAL mode, FTS toggle

**SQ2 — SQLite Adapter** (`packages/core/src/storage/sqlite.ts`)
- `SqliteStorageProvider` implementing `StorageProvider`
- better-sqlite3 with WAL mode, busy_timeout=5000, synchronous=NORMAL
- Prepared statements for all hot-path operations
- TTL: stored as epoch seconds, lazy deletion on read + periodic cleanup (60s interval)
- Optional FTS5 full-text search with content-sync triggers
- Transaction support via buffered ops pattern
- 53 tests covering CRUD, batch, query, TTL, FTS5, concurrency

**SQ3 — File Storage Adapter** (`packages/core/src/storage/file-store.ts`)
- `FileStore` implementing `StorageProvider`
- One JSON file per namespace at `{storeDir}/{namespace}.json`
- In-memory cache with lazy loading
- Atomic writes (temp file + rename)
- Per-namespace promise-chain mutex for concurrency
- TTL cleanup via configurable interval (default 60s)
- Transaction support with buffered ops
- 55 tests covering CRUD, batch, query, TTL, persistence, concurrency
