# 2026-07-07 · 20:xx — OpenAI Responses API 协议支持

## 变更

| 模块 | 内容 |
|---|---|
| core/adapters | 新增 `OpenAIResponsesAdapter`（`openai-responses.ts`），基于 OpenAI `/v1/responses` 协议实现 complete / stream / listModels；支持 instructions、function_call / function_call_output 历史回放、input_image、reasoning summary（thinking 事件）、max_output_tokens 截断映射、usage reasoning_tokens；固定 `store: false`（Vera 每轮回放完整历史，不依赖服务端状态链） |
| core/adapters | `llm-service.ts` 注册 `"openai-responses"` 内建 adapter factory；`resolveEnvKey` / `envVarFor` 将其归入 `OPENAI_API_KEY`；`base-url.ts` 归一化同样覆盖该 adapter（自动补 `/v1`） |
| partner/sidecar | `agent-run.ts` `adapterTypeForProtocol` 与 `llm-catalog.ts` 双向映射支持 `openai-responses` 协议 |
| partner/src-tauri | `agent.rs` `adapter_for_protocol` / `protocol_for_adapter` / env key 解析支持 `openai-responses` |
| partner/src | `LLMProtocol` 类型扩展；协议下拉新增 "OpenAI Responses"（原 "OpenAI Compatible" 更名 "OpenAI Chat Completions"）；`protocolFromEffective` 识别新 adapter；Base URL 提示覆盖两种 OpenAI 协议 |
| tests | 新增 `openai-responses.test.ts`（30 用例）；更新 `llm-protocol.test.ts` |
