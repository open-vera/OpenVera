## 详细说明

### CIGate (`packages/harness/src/benchmark/ci-gate.ts`)

- 包装 `RegressionDetector`，提供 CI 友好的 API
- `run(agent, cases)`: 运行 benchmark → 检查回归 → 记录结果 → 返回 exit code
- `check(result)`: 检查已有的 benchmark 结果（不运行）
- `formatReport(result)`: 输出 markdown 报告
- 阈值默认 5%，可配置

### CI Runner (`packages/harness/src/benchmark/ci-runner.ts`)

- CLI 入点：`npx tsx packages/harness/src/benchmark/ci-runner.ts --name gaia-l1 --model X --threshold 0.05 --history path`
- 加载 GAIA L1 cases（vera-custom.json 的 L1 子集）
- 支持自定义 cases 文件路径
- 写入 report.md 到 history 目录

### GitHub Actions Workflow (`.github/workflows/eval-regression.yml`)

- 触发条件：PR to main/develop/feature/** + workflow_dispatch
- 步骤：checkout → pnpm install → build core → 下载历史 → 跑 GAIA L1 → 上传历史+报告
- 历史作为 artifact 持久化（90 天），报告保留 30 天
