## Phase 16 CH4：API Channel — REST/WebSocket API

### 变更

| Hash | 模块 | 内容 |
|------|------|------|

### 实现要点

- **ApiChannelAdapter** (`packages/core/src/channel/api-channel.ts`) — 实现 `ChannelAdapter` 接口
- REST API：
  - `POST /messages` — 发送消息到 agent，返回 ChannelMessage
  - `GET /messages` — 查询消息历史，支持 limit/after/before/senderId 过滤
  - `GET /status` — 获取连接状态
  - `OPTIONS` — CORS preflight 支持
- WebSocket（RFC 6455 最小实现）：
  - HTTP upgrade 握手 + Sec-WebSocket-Accept 计算
  - 文本帧解析（opcode 0x01）、Ping/Pong（0x09/0x0a）、Close（0x08）
  - 客户端发送 `{ type: "message", content: "..." }` 触发消息分发
  - 服务端 `sendMessage()` 广播到所有 WS 客户端
- 认证：可选 API key，REST 通过 `Authorization: Bearer <key>`，WS 通过 `?token=<key>` 查询参数
- barrel export 更新到 `packages/core/src/channel/index.ts`

## Phase 16 CH3：CLI Channel

### 变更

| Hash | 模块 | 内容 |
|------|------|------|
| 551a4c9 | channel | feat: add CLI Channel adapter with interactive, pipe, and non-interactive modes |

### 实现要点

- **CliChannelAdapter** (`packages/core/src/channel/cli-channel.ts`) — 实现 `ChannelAdapter` 接口
- 三种模式：
  - **interactive**：基于 readline 的 REPL，支持 prompt 和逐行输入
  - **pipe**：读取所有 stdin 直到 EOF，作为单条消息分发（`echo "hello" | vera`）
  - **non-interactive**：通过 `processInput()` 方法编程式处理单条输入
- 可配置：自定义 input/output stream、prompt 字符串、senderId、ID 生成器
- 消息历史记录，支持 senderId 和 limit 过滤
- barrel export 更新到 `packages/core/src/channel/index.ts`

### 测试

- 24 tests，覆盖：
  - 三种模式的连接/断开生命周期
  - interactive 模式：readline 行处理、空行跳过、多行、流关闭断开
  - pipe 模式：EOF 触发、空输入、trim
  - non-interactive 模式：processInput、断开时抛错
  - sendMessage：输出到 stream、断开时抛错、附件、写入失败 ChannelSendError
  - onMessage：多回调、取消订阅、async 回调
  - getHistory：全量、senderId 过滤、limit
  - getStatus：状态跟踪、计数器
