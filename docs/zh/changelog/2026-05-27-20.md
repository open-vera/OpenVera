### 详情

**TrainingMonitor** (`packages/harness/src/training/webui/training-monitor.ts`)
- 轻量 HTTP 服务器，使用 Node 内置 `http` 模块，零新依赖
- SSE 端点 (`/api/events`)：实时推送 epoch 进度更新
- REST API：`/api/state`（当前状态）、`/api/history`（完整历史）
- HTML Dashboard (`/`)：暗色主题，Chart.js loss/accuracy 曲线图
- XSS 安全（HTML 转义）、CORS 支持、SSE 自动重连
- 通过 `createProgressCallback()` 与现有 Trainer 集成
- 支持 `notifyStart`/`notifyComplete`/`notifyFailed` 生命周期通知
- 默认端口 7394，绑定 `0.0.0.0` 支持远程访问

**测试**：25 tests 覆盖服务器生命周期、REST API、SSE 事件、状态管理、Dashboard HTML、XSS 防护
