# OpenVera v0.3.0 发布说明

OpenVera v0.3.0 聚焦于更顺滑的迁移体验、更好用的 CLI、更可靠的模型切换、更高效的本地开发调试，以及 **Vera Control Gateway** 控制面（工作区内可用）。

## 重点更新

### Claude Code 配置迁移

OpenVera 现在可以迁移已有的 Claude Code 配置，帮助用户把 provider、model、API Key 等设置带到 OpenVera 中，减少重复配置成本。

### 新增 `vera sync` 命令

新增 `vera sync` 命令，用于同步外部 agent 相关资源，让本地 OpenVera 资源（`.vera/`、skills 等）保持一致。

### CLI 别名

CLI 现在支持更多命令别名：

```bash
vera
ai
```

原有的 `openvera` 命令仍然可以继续使用。

### 首次启动配置向导

首次启动体验进一步优化。当 OpenVera 检测到尚未配置 API Key 时，会自动进入交互式配置向导，引导用户完成初始化。

### Vera Control Gateway（工作区）

本版本在 monorepo 内提供统一的 **Gateway 控制面**，聚合项目发现、能力清单、运行观测与管理动作，执行仍由 Core / Harness 负责。

- 新包：`@open-vera/gateway`（项目注册、能力描述符、Doctor 检查）
- 新应用：`apps/gateway-ui`（Vue 前端 + Node HTTP 服务）
- 统一 REST API：`/api/gateway/*`、`/api/projects`、`/api/runs`、`/api/conversations` 等（无旧 `/api/admin` 兼容层）
- 能力专页：Projects、Capabilities、Runs（Flow 启动 + 子路由详情）、Chat、RAG、MCP、Operations、Cost、Doctor

本地启动：

```bash
pnpm gateway-serve          # API 服务（默认 :7720）
pnpm ui                     # Web UI
pnpm gateway-serve:dist     # 使用编译产物启动 API
```

> Gateway UI 当前随仓库交付，尚未作为独立 npm 包发布；`openvera` CLI 安装包不包含 Web UI。

## Provider 与模型切换

REPL 中的 provider 和 model 切换更加可靠。OpenVera 现在会保留默认 provider model 的 fallback 行为，减少切换模型时默认配置被意外丢失或覆盖的情况。

## 开发体验

### Harness dev 直接加载 Core 源码

`openvera` / harness 的 dev 模式在 `--conditions=development` 下可直接解析 `@open-vera/core` 的 TypeScript 源码。修改 `packages/core/src` 后可通过：

```bash
pnpm dev
# 或
pnpm repl
```

测试最新源码，无需先手动 `pnpm --filter @open-vera/core build`。

### REPL 启动修复

修复 monorepo 下 `tsx` 未应用 `react-jsx` 导致的 `React is not defined` 问题：`App.tsx` 补充 React 导入，dev 脚本显式传入 `--tsconfig`。

## 质量与稳定性

本版本为多个核心模块补充了大量测试覆盖，包括：

- Adapters
- Configuration
- Tools
- Storage
- Memory
- MCP
- REPL
- Context
- Utilities
- Gateway（`@open-vera/gateway` 单元测试）

同时也完善了 CI 与覆盖率报告配置。

## 安装

```bash
npm install -g @open-vera/openvera@0.3.0
```

也可以使用：

```bash
npx @open-vera/openvera@0.3.0
```

从源码使用 Gateway：

```bash
git clone <repo>
cd open-vera && pnpm install
pnpm gateway-serve
pnpm ui
```

## 注意事项

- `0.3.0` npm 发布目前受 npm 认证或权限问题阻塞。若暂时无法安装该版本，说明 registry 发布尚未完成，恢复发布权限后会重新发布。
- Flow 与迭代产物目录使用 `.vera/flows/`（含 `iterations/`）；旧 `.flow/` 路径需自行迁移或重新初始化。
- Gateway 对话与 RAG 向量检索：已接入基础 API 与 Core `runAgent`；完整 MCP tool 调用、向量 embedding 检索为后续迭代项。
