# OpenVera v0.3.1 发布说明

OpenVera v0.3.1 是一个稳定性版本，聚焦于生产构建质量和减少日志噪音。

## 变更

### 生产构建改进

所有包的构建脚本现在注入 `NODE_ENV=production`，确保已发布的包默认使用 `info` 日志级别。除非通过 `VERA_LOG_LEVEL=debug` 或 `NODE_ENV=development` 显式开启，否则 debug 日志不会输出。

### 日志默认级别

- **默认级别从 `debug` 改为 `info`** — 生产安装不再向 stderr 输出 debug 日志
- `NODE_ENV=production` → `info` 级别
- `NODE_ENV=development` → `debug` 级别
- 未设置环境变量 → `info` 级别（安全的生产默认值）
- 显式覆盖：`VERA_LOG_LEVEL=debug`

### 状态消息接入 Logger

主入口文件（`packages/core/src/main.ts`）中硬编码的 `console.error` 调用已替换为标准 logger 调用，使状态消息遵守配置的日志级别。

### 历史变更（来自 v0.3.0）

- Claude Code 配置迁移
- `vera sync` 同步外部资源
- CLI 别名：`vera`、`ai`（除 `openvera` 外）
- 交互式首次运行配置向导
- Vera Control Gateway（monorepo 内）
- 改进 provider/model 切换可靠性
- Gateway UI（Vue Web + Node HTTP Server）

## 安装

```bash
npm install -g @open-vera/openvera@0.3.1
```

或使用 npx 运行：

```bash
npx @open-vera/openvera@0.3.1
```

启动 REPL：

```bash
ai
# 或使用: vera, openvera
```

## 说明

- Gateway UI 随仓库提供，尚未作为独立 npm 包发布
- `ai`、`vera`、`openvera` 三个命令等价，任选其一
- 开发时设置 `VERA_LOG_LEVEL=debug` 可查看 debug 日志
