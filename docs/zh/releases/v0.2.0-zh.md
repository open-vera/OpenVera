# OpenVera v0.2.0 发布说明

> 从 v0.1.0 到 v0.2.0，共 **231 commits**，涵盖 17 个功能模块的重大升级。
>
> [English Version](./v0.2.0.md)

---

## 🧠 Agent Core

- **三层记忆系统**：short-term / long-term / episodic memory，支持自动提取、组织、压缩、衰减、知识图谱
- **Session Manager**：自动压缩、去重、索引、生命周期管理（SS1-SS5）
- **Subagent 系统**：子代理池、后台任务、worktree 隔离（SA1-SA5）
- **Checkpoint / Resume / Fork**：完整的任务检查点系统，支持暂停、恢复、分叉
- **Self-Loop Runner**：自循环执行引擎 + CriticAgent 结果批判
- **Failure Attribution**：失败归因模块，支持 replay 分析
- **Intent Routing**：按任务复杂度 L0-L3 自动选模型
- **Infinite Context**：渐进式压缩、micro-compact、reactive compact

## 🛠 Tool Runtime

- **Middleware 系统**：工具调用链支持中间件注入（统计、鉴权、日志）
- **内置工具增强**：`read_file`、`write_file`、`edit_file`、`bash`、`grep`、`glob`、`list_dir`
- **Computer Use（CU1-CU16）**：
  - CDP 协议支持、浏览器会话管理
  - 桌面自动化（CU5-CU9）
  - `visual_analyze` — 截图 LLM 分析
  - 多步编排引擎（CU12）
  - 操作录制器（CU13）
  - WebArena 评测跑分 + 按站点报告（CU15-CU16）
- **Tool Lifecycle Hooks**：`onBeforeToolCall` / `onAfterToolCall` + AgentHooks 二级 hook 体系

## 🏖 Sandbox（SB1-SB12）

- **SandboxProvider 抽象层**：统一接口，支持多后端
- **CubeSandbox 适配器**：HTTP API 客户端，支持 exec/upload/download/readFile/stop/resume
- **Docker 本地沙箱适配器**
- **Sandbox Tools**：`sandbox_exec`、`sandbox_upload`、`sandbox_download`
- **Swarm Scheduler**：多沙箱并发调度
- **SandboxQuotaError / SandboxTimeoutError**：完善错误类型体系

## 📡 Channel 系统（CH1-CH7 + 平台适配器）

- **Channel 抽象层**：统一消息接口 + ChannelGateway 多 channel 管理
- **适配器**：CLI、REST API、Webhook、企业微信、Discord、Slack、WhatsApp
- **Plugin Registry**：运行时动态加载/卸载 channel adapter
- **并发场景测试**：多 channel 并发消息路由

## 🗄 Storage（SQ1-SQ8 + SP1-SP8）

- **StorageProvider 抽象**：SQLite + 文件适配器
- **Session SQLite 后端**：同步写入、导入/导出、数据迁移
- **Object Store**：多云适配器（S3/OSS/TOS）

## 🔍 RAG（R1-R9）

- **VectorStore**：SQLite-backed 余弦相似度搜索
- **EmbeddingAdapter**：嵌入向量适配层
- **Document Loader**：Markdown/JSON/TypeScript/文本批量索引
- **`knowledge_search` 工具**：RAG 检索集成
- **增量索引**：基于 mtime 的变更检测

## 📊 Eval & Benchmark（EV1-EV8 + B1-B7）

- **评测框架**：自定义测试用例 + GAIA runner
- **SWE-bench**：代码修复评测
- **WebArena**：Web 任务评测 + 按站点报告
- **ToolBench**：16,464 任务工具使用评测
- **回归检测**：CIGate + CI workflow（EV7）
- **Benchmark 系统**：回归检测 + 趋势分析

## 🎯 Strategy（AD1-AD5）

- **StrategyStore**：按任务域存储策略配置 + 成果追踪
- **Historical Success Rate**：时间窗口统计、趋势检测
- **Auto-Tuner**：UCB1 策略选择、复合评分
- **A/B Testing**：并行策略对比 + 统计显著性检验

## 💡 Dreaming & Proposal（DR1-DR5 + PP1-PP6）

- **经验蒸馏**：从执行历史中提取可复用经验
- **Proposal Pipeline**：改进提案 → 验证 → 生效的完整生命周期

## 🧩 MCP & Multi-Agent

- **MCP Client**：外部工具服务器集成（MC1-MC5）
- **Multi-Agent Network**：多 agent 协作网络（MN1-MN5）

## 🖥 REPL UI

- **Session Picker**：交互式会话选择器 + 恢复
- **Tool 渲染器**：DiffView、CodeView、BashOutputView、FileListView、ErrorView、TextView
- **Live Output Streaming**：bash stdout/stderr 实时推送到 ActivityLane
- **Thinking/Reasoning 展示**：LLM thinking token 实时显示
- **Setup Wizard**：首次运行交互式配置向导
- **主题系统**：统一配色方案
- **debugLog 诊断工具**：session resume 流程调试

## 🖥 Web UI

- **Admin UI**：服务端 + Web 前端，Dashboard、空间管理、设置
- **Core UI**：内存查看器、会话管理
- **Harness UI**：RunList、运行监控
- **Training Monitor**：SkillOpt 训练进度实时面板

## 🔧 Adapter 增强

- **Anthropic**：thinking 参数 / thinking_delta / thinking content block
- **OpenAI**：reasoning_content（DeepSeek 兼容）、reasoning_tokens 追踪
- **Gemini**：usage reporting 修复

## 📦 Infrastructure

- **pnpm workspace monorepo**：Core / Harness / UI 分包
- **TypeScript strict mode**：全量类型检查
- **Vitest 测试框架**：2,100+ 测试用例
- **Pre-commit hook**：凭证扫描
- **CubeSandbox HTTP 工具函数重构**：共享 requestCubeSandbox
