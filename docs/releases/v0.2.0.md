# OpenVera v0.2.0 Release Notes

> **231 commits** from v0.1.0 to v0.2.0 — a major upgrade spanning 17 feature modules.
>
> [中文版本](./v0.2.0-zh.md)

---

## 🧠 Agent Core

- **Three-tier memory system**: short-term / long-term / episodic memory with auto-extraction, organization, compression, decay, and knowledge graph
- **Session Manager**: auto-compression, deduplication, indexing, and lifecycle management (SS1–SS5)
- **Subagent system**: agent pool, background jobs, worktree isolation (SA1–SA5)
- **Checkpoint / Resume / Fork**: full task checkpoint system with pause, resume, and fork support
- **Self-Loop Runner**: self-cycling execution engine + CriticAgent result critique
- **Failure Attribution**: failure root-cause analysis module with replay support
- **Intent Routing**: automatic model selection by task complexity (L0–L3)
- **Infinite Context**: progressive compression, micro-compact, reactive compact

## 🛠 Tool Runtime

- **Middleware system**: tool call chain supports middleware injection (analytics, auth, logging)
- **Built-in tool enhancements**: `read_file`, `write_file`, `edit_file`, `bash`, `grep`, `glob`, `list_dir`
- **Computer Use (CU1–CU16)**:
  - CDP protocol support, browser session management
  - Desktop automation (CU5–CU9)
  - `visual_analyze` — screenshot LLM analysis
  - Multi-step orchestration engine (CU12)
  - Operation recorder (CU13)
  - WebArena benchmark runner + per-site reports (CU15–CU16)
- **Tool Lifecycle Hooks**: `onBeforeToolCall` / `onAfterToolCall` + AgentHooks two-tier hook system

## 🏖 Sandbox (SB1–SB12)

- **SandboxProvider abstraction**: unified interface with pluggable backends
- **CubeSandbox adapter**: HTTP API client — exec, upload, download, readFile, stop, resume
- **Docker local sandbox adapter**
- **Sandbox Tools**: `sandbox_exec`, `sandbox_upload`, `sandbox_download`
- **Swarm Scheduler**: multi-sandbox concurrent scheduling
- **SandboxQuotaError / SandboxTimeoutError**: improved error type hierarchy

## 📡 Channel System (CH1–CH7 + Platform Adapters)

- **Channel abstraction layer**: unified message interface + ChannelGateway multi-channel management
- **Adapters**: CLI, REST API, Webhook, WeCom, Discord, Slack, WhatsApp
- **Plugin Registry**: runtime dynamic loading/unloading of channel adapters
- **Concurrent scenario tests**: multi-channel concurrent message routing

## 🗄 Storage (SQ1–SQ8 + SP1–SP8)

- **StorageProvider abstraction**: SQLite + file adapters
- **Session SQLite backend**: synchronous writes, import/export, data migration
- **Object Store**: multi-cloud adapters (S3 / OSS / TOS)

## 🔍 RAG (R1–R9)

- **VectorStore**: SQLite-backed cosine similarity search
- **EmbeddingAdapter**: embedding vector abstraction layer
- **Document Loader**: Markdown / JSON / TypeScript / plain-text batch indexing
- **`knowledge_search` tool**: RAG retrieval integration
- **Incremental indexer**: mtime-based change detection

## 📊 Eval & Benchmark (EV1–EV8 + B1–B7)

- **Evaluation framework**: custom test cases + GAIA runner
- **SWE-bench**: code repair evaluation
- **WebArena**: web task evaluation + per-site reports
- **ToolBench**: 16,464-task tool usage benchmark
- **Regression detection**: CIGate + CI workflow (EV7)
- **Benchmark system**: regression detection + trend analysis

## 🎯 Strategy (AD1–AD5)

- **StrategyStore**: task-domain-based strategy configuration + outcome tracking
- **Historical Success Rate**: windowed statistics, trend detection
- **Auto-Tuner**: UCB1 strategy selection, composite scoring
- **A/B Testing**: parallel strategy comparison + statistical significance testing

## 💡 Dreaming & Proposal (DR1–DR5 + PP1–PP6)

- **Experience distillation**: extract reusable experience from execution history
- **Proposal Pipeline**: improvement proposal → validation → rollout lifecycle

## 🧩 MCP & Multi-Agent

- **MCP Client**: external tool server integration (MC1–MC5)
- **Multi-Agent Network**: multi-agent collaboration network (MN1–MN5)

## 🖥 REPL UI

- **Session Picker**: interactive session selector + resume
- **Tool renderers**: DiffView, CodeView, BashOutputView, FileListView, ErrorView, TextView
- **Live Output Streaming**: bash stdout/stderr streamed to ActivityLane in real-time
- **Thinking/Reasoning display**: LLM thinking token real-time visualization
- **Setup Wizard**: interactive first-run configuration wizard
- **Theme system**: unified color scheme
- **debugLog diagnostics**: session resume flow debugging

## 🖥 Web UI

- **Admin UI**: server + web frontend — dashboard, space management, settings
- **Core UI**: memory viewer, session management
- **Harness UI**: RunList, run monitoring
- **Training Monitor**: SkillOpt training progress real-time panel

## 🔧 Adapter Enhancements

- **Anthropic**: thinking parameter / thinking_delta / thinking content block
- **OpenAI**: reasoning_content (DeepSeek-compatible), reasoning_tokens tracking
- **Gemini**: usage reporting fix

## 📦 Infrastructure

- **pnpm workspace monorepo**: Core / Harness / UI package split
- **TypeScript strict mode**: full type checking
- **Vitest test framework**: 2,100+ test cases
- **Pre-commit hook**: credential scanning
- **CubeSandbox HTTP utility refactor**: shared `requestCubeSandbox`
