## 1. 概述

本文档包含 TaskFlow 项目 P0-P2 优先级的全部用户故事，采用标准的 **As a [角色], I want [功能], So that [价值]** 格式编写，每个故事附带可验证的验收标准（Acceptance Criteria）。

**统计**:
- P0 用户故事: 13 个
- P1 用户故事: 5 个
- P2 用户故事: 3 个
- **合计: 21 个用户故事**

---

## 2. P0 用户故事（MVP 必须实现）

### 2.1 用户认证模块

#### US-001: 新用户注册

**As a** 新用户  
**I want** 通过邮箱和密码注册一个账号  
**So that** 我可以拥有个人专属的任务空间

**优先级**: P0  
**关联功能**: F01 用户注册与登录

**验收标准**:

1. Given 我在注册页面，When 我输入有效的邮箱地址、≥8 位的密码和确认密码并点击"注册"，Then 系统创建我的账号并跳转到登录页，显示注册成功提示
2. Given 我在注册页面，When 我输入已被注册的邮箱，Then 系统在邮箱输入框下方显示"该邮箱已被注册"错误信息
3. Given 我在注册页面，When 我输入少于 8 位的密码，Then 系统在密码输入框下方显示"密码长度至少为 8 位"提示
4. Given 我在注册页面，When 我输入的确认密码与密码不一致，Then 系统显示"两次密码不一致"提示
5. Given 我在注册页面，When 我输入格式无效的邮箱（如缺少 @），Then 系统显示"请输入有效的邮箱地址"提示
6. Given 我在注册页面，When 我留空必填字段并点击注册，Then 必填字段高亮并显示"此项为必填项"提示

---

#### US-002: 用户登录

**As a** 已注册用户  
**I want** 通过邮箱和密码登录我的账号  
**So that** 我可以访问自己的任务数据

**优先级**: P0  
**关联功能**: F01 用户注册与登录

**验收标准**:

1. Given 我在登录页面，When 我输入正确的邮箱和密码并点击"登录"，Then 系统验证通过，跳转到任务列表页
2. Given 我在登录页面，When 我输入错误的密码，Then 系统显示"邮箱或密码错误"提示（不明确告知是密码错误，防止账号枚举）
3. Given 我在登录页面，When 我输入未注册的邮箱，Then 系统同样显示"邮箱或密码错误"提示
4. Given 我登录成功，When 我关闭浏览器后重新打开，Then 在 Token 有效期内我可以继续访问任务页（无需重新登录）
5. Given 我在登录页面，When 登录请求正在处理中，Then "登录"按钮显示加载状态并不可重复点击

---

#### US-003: 用户退出登录

**As a** 已登录用户  
**I want** 一键退出登录  
**So that** 在共享设备上我可以保护我的数据隐私

**优先级**: P0  
**关联功能**: F01 用户注册与登录

**验收标准**:

1. Given 我已登录，When 我点击"退出登录"按钮，Then 系统清除我的 Token 并跳转到登录页
2. Given 我已退出登录，When 我尝试直接访问任务列表页（通过 URL），Then 系统重定向到登录页
3. Given 我已退出登录，When 我点击浏览器后退按钮，Then 我不会回到任务列表页

---

#### US-004: Token 过期自动处理

**As a** 已登录用户  
**I want** 当我的登录凭证过期时被自动引导到登录页  
**So that** 我知道需要重新登录，而不会遇到无法理解的错误

**优先级**: P0  
**关联功能**: F01 用户注册与登录

**验收标准**:

1. Given 我已登录但 Token 已过期，When 我执行任何操作（如创建任务），Then 系统重定向到登录页并显示"登录已过期，请重新登录"提示
2. Given 我在登录页因 Token 过期跳转过来，When 我重新登录成功，Then 系统跳转到我之前尝试访问的页面（如任务列表）

---

### 2.2 任务管理模块

#### US-005: 创建新任务

**As a** 已登录用户  
**I want** 快速创建一条新任务  
**So that** 我可以记录需要完成的工作事项

**优先级**: P0  
**关联功能**: F02 任务 CRUD

**验收标准**:

1. Given 我在任务列表页，When 我点击"新建任务"按钮并输入标题后确认，Then 新任务出现在列表顶部，状态默认为"待办"，优先级默认为"中"
2. Given 我在创建任务时，When 我填写标题、描述、选择优先级为"高"并设置截止日期为明天，Then 创建的任务包含我填写的所有信息
3. Given 我在创建任务时，When 我留空标题并点击确认，Then 系统显示"标题不能为空"错误提示
4. Given 我在创建任务时，When 我输入超过 200 字符的标题，Then 系统提示标题超出字符限制
5. Given 我在创建任务时，When 我输入超过 2000 字符的描述，Then 系统提示描述超出字符限制
6. Given 我成功创建任务，When 新任务出现在列表中，Then 同时显示标题、优先级图标和截止日期

---

#### US-006: 查看任务详情

**As a** 已登录用户  
**I want** 点击一条任务查看它的完整详情  
**So that** 我可以看到任务描述、所有字段和历史信息

**优先级**: P0  
**关联功能**: F02 任务 CRUD

**验收标准**:

1. Given 我在任务列表页，When 我点击某条任务，Then 跳转到任务详情页，显示标题、描述、优先级、截止日期、状态、创建时间和更新时间
2. Given 我在任务详情页，When 任务描述为空，Then 描述区域显示"暂无描述"或不显示
3. Given 我在任务详情页，When 任务无截止日期，Then 截止日期显示为"未设置"

---

#### US-007: 编辑任务

**As a** 已登录用户  
**I want** 修改已有任务的任何信息  
**So that** 我可以更新任务的要求或纠正错误信息

**优先级**: P0  
**关联功能**: F02 任务 CRUD

**验收标准**:

1. Given 我在任务详情页或列表中，When 我点击"编辑"按钮，Then 任务字段变为可编辑状态
2. Given 我在编辑模式下，When 我修改标题并点击"保存"，Then 任务标题更新，更新时间刷新
3. Given 我在编辑模式下，When 我修改优先级从"中"到"高"，Then 列表中优先级显示同步更新
4. Given 我在编辑模式下，When 我清空截止日期，Then 任务的截止日期变为未设置状态
5. Given 我在编辑模式下，When 我清空标题并保存，Then 系统提示"标题不能为空"
6. Given 我在编辑模式下，When 我点击"取消"，Then 所有修改被丢弃，恢复原始数据

---

#### US-008: 删除任务

**As a** 已登录用户  
**I want** 删除不再需要的任务  
**So that** 我的任务列表保持整洁

**优先级**: P0  
**关联功能**: F02 任务 CRUD

**验收标准**:

1. Given 我在任务列表或详情页，When 我点击"删除"按钮，Then 系统弹出确认对话框，显示"确定要删除此任务吗？此操作不可恢复"
2. Given 确认对话框已弹出，When 我点击"确认删除"，Then 任务从列表中移除
3. Given 确认对话框已弹出，When 我点击"取消"，Then 对话框关闭，任务保持不变
4. Given 任务已成功删除，When 操作完成，Then 显示"任务已删除"的短暂提示（Toast）

---

### 2.3 任务列表与筛选模块

#### US-009: 浏览任务列表

**As a** 已登录用户  
**I want** 在一个页面上看到我所有的任务  
**So that** 我可以快速了解当前的工作全貌

**优先级**: P0  
**关联功能**: F03 任务列表与筛选

**验收标准**:

1. Given 我已登录并有任务数据，When 我进入任务列表页，Then 显示我创建的所有任务，按创建时间倒序排列（最新创建的在最前面）
2. Given 我有多条任务，When 列表展示，Then 每条任务显示标题、状态、优先级和截止日期
3. Given 我有超过 20 条任务，When 列表加载，Then 分页显示，每页 20 条，底部有分页控件
4. Given 我没有任何任务，When 我进入列表页，Then 显示空状态页面，包含"还没有任务，创建你的第一条任务"的引导文案和创建按钮

---

#### US-010: 按状态筛选任务

**As a** 已登录用户  
**I want** 按任务状态（待办/进行中/已完成）筛选任务列表  
**So that** 我可以专注于某一类状态的任务

**优先级**: P0  
**关联功能**: F03 任务列表与筛选

**验收标准**:

1. Given 我在任务列表页，When 我选择筛选条件为"待办"，Then 列表只显示状态为待办的任务
2. Given 我已筛选为"待办"，When 我切换为"已完成"，Then 列表更新为只显示已完成的任务
3. Given 我已筛选为"进行中"，When 我选择"全部"，Then 列表恢复显示所有状态的任务
4. Given 我设置了状态筛选，When 刷新页面，Then 筛选条件保持不变

---

#### US-011: 按优先级筛选任务

**As a** 已登录用户  
**I want** 按优先级（高/中/低）筛选任务  
**So that** 我可以先处理最重要的事情

**优先级**: P0  
**关联功能**: F03 任务列表与筛选

**验收标准**:

1. Given 我在任务列表页，When 我选择筛选条件为"高优先级"，Then 列表只显示高优先级的任务
2. Given 我已筛选"高优先级"，When 我同时设置状态筛选为"待办"，Then 列表只显示"高优先级且待办"的任务
3. Given 多个筛选条件叠加，When 结果为空，Then 显示"暂无符合条件的任务"

---

#### US-012: 按截止日期排序

**As a** 已登录用户  
**I want** 按截止日期排序任务  
**So that** 我可以优先处理即将到期的任务

**优先级**: P0  
**关联功能**: F03 任务列表与筛选

**验收标准**:

1. Given 我在任务列表页，When 我选择"截止日期升序"排序，Then 最早到期的任务排在最前面
2. Given 我选择"截止日期降序"排序，Then 最晚到期的任务排在最前面
3. Given 有些任务没有设置截止日期，When 按截止日期排序，Then 无截止日期的任务排在有截止日期的任务之后

---

### 2.4 任务状态流转模块

#### US-013: 切换任务状态

**As a** 已登录用户  
**I want** 通过点击一键切换任务状态  
**So that** 我可以快速推进任务进度

**优先级**: P0  
**关联功能**: F04 任务状态流转

**验收标准**:

1. Given 我在任务列表页，When 我点击状态为"待办"的任务的状态按钮，Then 状态立即变为"进行中"，无需手动保存
2. Given 任务状态为"进行中"，When 我点击状态按钮，Then 状态变为"已完成"，任务显示完成样式（如删除线）
3. Given 任务状态为"已完成"，When 我点击状态按钮，Then 状态回退为"待办"
4. Given 我连续快速点击状态按钮，When 系统处理中，Then 防抖处理，避免重复请求导致状态不一致
5. Given 网络请求失败，When 状态变更的 API 调用出错，Then 任务状态恢复为变更前的值，并显示"操作失败，请重试"提示

## 3. P1 用户故事（增强功能）

### 3.1 标签系统

#### US-014: 为任务添加标签

**As a** 已登录用户  
**I want** 为任务添加自定义标签（如"工作"、"紧急"、"学习"）  
**So that** 我可以按类别组织和识别任务

**优先级**: P1  
**关联功能**: F06 任务分类（标签系统）

**验收标准**:

1. Given 我在创建或编辑任务时，When 我在标签栏输入"工作"并回车，Then 标签"工作"被添加到任务上
2. Given 任务已有标签"工作"，When 我再次添加"工作"，Then 系统提示"该标签已存在"
3. Given 我要添加标签，When 我输入超过 20 字符的标签名，Then 系统提示标签名过长
4. Given 任务已有 10 个标签，When 我尝试添加第 11 个，Then 系统提示"最多添加 10 个标签"
5. Given 我在任务上看到标签，When 我点击标签旁的删除图标，Then 该标签从任务上移除

---

#### US-015: 按标签筛选任务

**As a** 已登录用户  
**I want** 在任务列表中按标签筛选  
**So that** 我可以快速查看某一类别的所有任务

**优先级**: P1  
**关联功能**: F06 任务分类（标签系统）

**验收标准**:

1. Given 我在任务列表页，When 我在标签筛选区域选择"工作"标签，Then 列表只显示包含"工作"标签的任务
2. Given 我已选择一个标签筛选，When 我再选择另一个标签，Then 列表显示同时包含两个标签的任务（AND 逻辑）或包含任一标签的任务（OR 逻辑，需产品决策）
3. Given 标签筛选区域，When 我查看标签列表，Then 显示所有已有标签及每个标签关联的任务数量

---

### 3.2 搜索功能

#### US-016: 搜索任务

**As a** 已登录用户  
**I want** 通过关键词搜索任务  
**So that** 我可以快速找到特定任务

**优先级**: P1  
**关联功能**: F07 任务搜索

**验收标准**:

1. Given 我在任务列表页，When 我在搜索框输入"项目报告"，Then 列表只显示标题或描述中包含"项目报告"的任务
2. Given 我正在输入搜索词，When 我停止输入超过 300ms，Then 才发起搜索请求（防抖）
3. Given 搜索关键词为"report"，When 任务描述中包含"Report"，Then 该任务出现在结果中（不区分大小写）
4. Given 我清空搜索框，When 搜索框变为空，Then 列表恢复显示全部任务
5. Given 搜索无结果，When 返回空列表，Then 显示"未找到包含'xxx'的任务"提示
6. Given 我已设置状态筛选为"待办"，When 我同时搜索"报告"，Then 结果为"状态为待办且标题/描述包含'报告'"的任务

---

### 3.3 统计仪表盘

#### US-017: 查看任务统计

**As a** 已登录用户  
**I want** 在仪表盘页面看到任务的整体统计  
**So that** 我可以直观了解工作进度和待办概况

**优先级**: P1  
**关联功能**: F08 任务统计仪表盘

**验收标准**:

1. Given 我进入仪表盘页面，When 页面加载完成，Then 显示我的任务总数
2. Given 仪表盘已加载，When 我查看状态分布，Then 以图表或数字卡片形式显示待办、进行中、已完成各多少条，以及占比百分比
3. Given 仪表盘已加载，When 我查看"本周到期"卡片，Then 显示本周一到周日期间到期的任务数量
4. Given 有任务已过截止日期但状态不是"已完成"，When 我查看仪表盘，Then "已逾期"区域用醒目颜色（如红色）显示逾期任务数量
5. Given 我创建了新任务，When 我返回仪表盘页面，Then 统计数据已更新（刷新后生效）

## 4. P2 用户故事（体验优化）

### 4.1 拖拽排序

#### US-018: 拖拽调整任务顺序

**As a** 已登录用户  
**I want** 通过拖拽来调整任务在列表中的顺序  
**So that** 我可以按个人优先级排列任务

**优先级**: P2  
**关联功能**: F09 拖拽排序

**验收标准**:

1. Given 我在任务列表页，When 我按住一条任务并拖拽到新位置，Then 拖拽过程中有视觉反馈（半透明占位符）
2. Given 我拖拽任务到新位置并释放，When 拖拽完成，Then 任务顺序更新并自动保存
3. Given 我在移动端操作，When 我长按任务卡片，Then 进入拖拽模式

---

### 4.2 批量操作

#### US-019: 批量修改任务状态

**As a** 已登录用户  
**I want** 选中多条任务后批量修改它们的状态  
**So that** 我可以高效地处理大量已完成或不再需要的任务

**优先级**: P2  
**关联功能**: F10 批量操作

**验收标准**:

1. Given 我在任务列表页，When 我点击"批量操作"按钮进入多选模式，Then 每条任务前出现复选框
2. Given 多选模式下，When 我勾选 5 条任务并选择"批量标记为已完成"，Then 这 5 条任务状态变为"已完成"
3. Given 多选模式下，When 我点击"全选"，Then 当前页所有任务被选中
4. Given 我选中 3 条任务并点击"批量删除"，When 确认弹窗出现并我点击确认，Then 3 条任务被删除，显示"已删除 3 条任务"

---

### 4.3 深色模式

#### US-020: 切换深色模式

**As a** 已登录用户  
**I want** 切换到深色主题  
**So that** 在低光环境下减少眼睛疲劳

**优先级**: P2  
**关联功能**: F11 深色模式

**验收标准**:

1. Given 我在应用中，When 我点击主题切换按钮，Then 界面从浅色模式切换为深色模式，所有元素颜色适配
2. Given 我切换到深色模式，When 我刷新页面，Then 仍然是深色模式（偏好已保存）
3. Given 我的系统设置为深色模式，When 我首次打开应用，Then 自动使用深色主题

---

#### US-021: 自适应系统主题偏好

**As a** 已登录用户  
**I want** 应用自动跟随我的系统主题偏好  
**So that** 应用与系统保持一致的视觉风格

**优先级**: P2  
**关联功能**: F11 深色模式

**验收标准**:
