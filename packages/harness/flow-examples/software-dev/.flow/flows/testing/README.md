# 测试验证

## 职责

测试工程师和开发工程师共同制定和执行测试方案，确保功能质量。

## 参与角色

- **tester**: 测试计划、用例设计、测试执行、报告输出
- **developer**: 协助问题定位、缺陷修复

## 输入

- 开发实现产物: [flows/implement/output/](../implement/output/)

## 交付产物（写入项目目录）

写入 `../project/docs/`：

- `test-plan.md` — 测试计划（范围、策略、通过标准）
- `test-report.md` — 测试报告（用例执行结果、缺陷列表、质量总结）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（测试结论、遗留问题、给发布的注意事项）

## 准出标准

- 所有 P0 功能用例通过
- P1 功能用例通过率 ≥ 90%
- 无 P0 级别阻断性缺陷
- 性能测试达到基准要求
- 最低得分: 0.8
