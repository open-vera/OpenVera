# 需求分析

## 职责

产品经理和用户代表共同分析功能需求，进行优先级排序和用户故事拆解。

## 参与角色

- **pm**: 主导需求分析，竞品调研，优先级排序
- **user**: 从目标用户视角评估需求合理性

## 输入

- 任务目标: [goal.md](../../task/goal.md)

## 交付产物（写入项目目录）

写入 `../project/docs/`：

- `prd.md` — 产品需求文档，含功能列表、优先级、验收标准
- `user-stories.md` — 用户故事列表（As a... I want... So that...）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（做了什么、给下一步的注意事项）

## 准出标准

- 覆盖 goal.md 中全部核心功能
- 每个功能有 P0-P3 优先级标注
- 每个用户故事有明确的验收标准
- MVP 范围清晰（P0 功能集）
- 最低得分: 0.8
