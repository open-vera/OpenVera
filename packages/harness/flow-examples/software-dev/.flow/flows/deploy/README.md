# 发布上线

## 职责

开发工程师和运维工程师共同制定并执行发布方案，确保应用稳定上线。

## 参与角色

- **developer**: 发布脚本、配置管理、发布后验证
- **ops**: 部署方案、监控配置、回滚预案

## 输入

- 测试验证产物: [flows/testing/output/](../testing/output/)

## 交付产物（写入项目目录）

写入 `../project/docs/`：

- `deploy-guide.md` — 部署手册（环境要求、步骤、配置说明）
- `runbook.md` — 运维手册（监控指标、告警处理、回滚流程）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（发布结果、线上验证结论、遗留事项）

## 准出标准

- 应用成功部署并通过冒烟测试
- 监控和告警配置完成
- 回滚方案就绪
- 部署文档完整可复现
- 最低得分: 0.85
