# 任务目标

> 开发一个轻量级的**个人任务管理 Web 应用**（TaskFlow），帮助用户高效管理日常待办事项，支持任务的创建、编辑、分类、搜索和完成标记等核心操作。

## 背景

个人和小型团队在日常工作中需要管理大量待办事项，但现有的任务管理工具要么过于复杂（如 Jira、Asana），要么功能单薄（如纯文本备忘录）。市场需要一款**简洁但功能完备**的任务管理工具，介于两者之间，面向个人用户和 2-5 人的小型团队。

**目标用户**：
- 个人开发者、自由职业者
- 小型项目团队成员
- 需要结构化管理待办事项的知识工作者

**核心价值主张**：用最少的操作步骤完成任务的录入、追踪和归档，保持界面清爽不干扰。

## 核心功能

### P0（MVP 必须实现）

1. **用户注册与登录** — 支持邮箱/密码注册，JWT 令牌认证，会话管理
2. **任务 CRUD** — 创建、查看、编辑、删除任务，每条任务包含标题、描述、优先级、截止日期、状态
3. **任务列表与筛选** — 按状态（待办/进行中/已完成）、优先级（高/中/低）筛选，按截止日期排序
4. **任务状态流转** — 待办 → 进行中 → 已完成，支持一键状态切换
5. **响应式 Web 界面** — 适配桌面和移动端浏览器的基本布局

### P1（增强功能）

6. **任务分类（标签系统）** — 为任务添加多个自定义标签，按标签筛选任务
7. **任务搜索** — 按标题和描述关键词全文搜索
8. **任务统计仪表盘** — 显示总任务数、各状态分布、本周到期任务数等概览信息

### P2（体验优化）

9. **拖拽排序** — 支持任务列表的拖拽排序调整优先级
10. **批量操作** — 多选任务后批量修改状态或删除
11. **深色模式** — 支持浅色/深色主题切换

### P3（远期规划，本期不实现）

12. 多人协作与任务分配
13. 文件附件上传
14. 邮件/浏览器通知提醒

## 技术要求

- **前端**: React 18 + TypeScript，使用 Vite 构建，组件库不限（可选 Tailwind CSS 或 shadcn/ui）
- **后端**: Node.js + Express（或 Fastify），TypeScript
- **数据库**: SQLite（轻量级，无需额外数据库服务，便于本地开发和演示）
- **认证**: JWT（JSON Web Token），bcrypt 密码哈希
- **API 风格**: RESTful JSON API
- **代码规范**: ESLint + Prettier，有意义的 Git 提交信息

### 性能要求

- 页面首次加载时间 < 2 秒（本地环境）
- API 接口响应时间 < 200ms（单用户场景）
- 支持同时管理至少 500 条任务而无明显性能下降

### 部署环境

- **开发环境**: 本地 Node.js 运行，Vite 开发服务器
- **部署方式**: 本地可独立运行（`npm start` 一键启动），提供 Dockerfile 支持容器化部署
- **无需外部依赖**: 不依赖云服务、第三方 API 或外部数据库

## 约束条件

- **时间**: 在当前开发流程周期内完成（需求→设计→开发→测试→发布全流程）
- **团队规模**: 由 AI agent 协作完成（产品经理、用户代表、设计师、开发工程师、测试工程师、运维工程师各 1 名）
- **项目范围**: MVP（P0 功能）为必须交付物，P1 功能尽力完成，P2 功能仅在时间允许时实现
- **安全要求**: 密码加密存储，API 鉴权保护，基本的输入校验防注入
- **质量要求**: 核心功能单元测试覆盖率 ≥ 70%，无 P0 级别缺陷
- **文档要求**: 附带 README.md，包含项目介绍、本地运行步骤、API 概览
