## 1. 任务目标回顾

根据 `.flow/task/goal.md`，目标是开发 **TaskFlow** — 一款轻量级个人任务管理 Web 应用，面向个人开发者、自由职业者和 2-5 人小型团队，提供简洁但功能完备的任务管理体验。

## 4. MVP 范围

MVP 严格限定为 **P0 功能（F01-F05）**，验收条件：

1. 用户可注册、登录、退出，Token 过期自动跳转登录
2. 用户可创建、查看、编辑、删除自己的任务
3. 任务列表支持按状态/优先级筛选，按日期排序
4. 任务状态可通过点击一键流转
5. 在桌面和移动浏览器中均可正常使用全部功能
6. API 响应时间 < 200ms，500 条任务不卡顿
7. 核心功能单元测试覆盖率 ≥ 70%
8. 无 P0 级别缺陷

## 6. 关键决策记录

| 编号 | 决策 | 理由 |
|------|------|------|
| D01 | JWT Token 存储于 localStorage | MVP 简化实现，生产环境可升级 httpOnly Cookie |
| D02 | 删除操作不可恢复 | MVP 范围不做回收站，通过确认对话框防护 |
| D03 | 标签筛选采用 OR 逻辑 | 符合用户直觉，扩大结果集更实用 |
| D04 | 任务排序使用 sort_order 浮点数权重 | 支持拖拽排序时的灵活插入 |
| D05 | 搜索使用 SQLite LIKE 查询 | P1 简化实现，可后续升级为 FTS5 |
