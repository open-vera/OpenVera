## 概述

本文档以用户故事（User Story）格式梳理 TaskFlow 的全部功能需求，每条故事包含角色、需求描述、目的、验收标准和优先级。

## P0 — 用户认证

### US-01 用户注册

> **As a** 新用户  
> **I want** 通过邮箱和密码注册一个账号  
> **So that** 我可以创建个人专属的任务空间，数据与其他用户隔离

**验收标准 (AC)**：
1. 访问 `/register` 页面展示注册表单，包含邮箱、密码、确认密码字段
2. 输入有效邮箱（符合 RFC 5322 格式）、密码（≥ 8 位，含大小写字母和数字）和确认密码后点击注册，账号创建成功并自动登录
3. 密码与确认密码不一致时，表单提示「两次密码不一致」
4. 密码强度不满足要求时，给出明确的格式要求提示
5. 使用已注册的邮箱再次注册时，提示「该邮箱已被注册」
6. 邮箱格式不正确时，提示「请输入有效的邮箱地址」

**优先级**: P0

---

### US-02 用户登录

> **As a** 已注册用户  
> **I want** 使用邮箱和密码登录系统  
> **So that** 我可以安全地访问我的任务数据

**验收标准 (AC)**：
1. 访问 `/login` 页面展示登录表单，包含邮箱和密码字段
2. 输入正确的邮箱和密码后成功登录，跳转到任务列表页
3. 输入错误密码时提示「邮箱或密码错误」（不单独提示哪个错误，防止枚举攻击）
4. 登录成功后 JWT Token 存储在客户端，有效期 24 小时
5. Token 过期后访问任何受保护页面，自动跳转到登录页并提示「登录已过期，请重新登录」

**优先级**: P0

---

### US-03 用户登出

> **As a** 已登录用户  
> **I want** 能够安全退出登录  
> **So that** 在共享设备上使用后，我的数据不会被他人访问

**验收标准 (AC)**：
1. 用户菜单中包含「退出登录」选项
2. 点击后清除本地 Token 并跳转到登录页
3. 退出后访问受保护页面被重定向到登录页

**优先级**: P0

## P0 — 任务管理

### US-04 创建任务

> **As a** 已登录用户  
> **I want** 快速创建一个新任务  
> **So that** 我可以记录下需要完成的工作事项

**验收标准 (AC)**：
1. 任务列表页有醒目的「新建任务」按钮
2. 点击后弹出创建表单或进入创建页面，包含标题（必填）、描述（选填）、优先级（选填，默认中）、截止日期（选填）
3. 填写标题后点击保存，任务创建成功并出现在列表中
4. 新创建的任务状态默认为「待办」
5. 标题为空时提交，提示「请输入任务标题」
6. 标题超过 200 字符时提示「标题不能超过 200 个字符」
7. 描述超过 2000 字符时提示「描述不能超过 2000 个字符」
8. 创建成功后表单自动关闭或清空，给出「任务已创建」的成功提示

**优先级**: P0

---

### US-05 查看任务详情

> **As a** 已登录用户  
> **I want** 查看某个任务的完整详情  
> **So that** 我可以了解任务的所有信息，包括描述、截止日期等

**验收标准 (AC)**：
1. 点击任务列表中的任务标题，跳转到任务详情页或展开详情面板
2. 详情页展示：标题、描述、优先级、状态、截止日期、创建时间、更新时间
3. 优先级以颜色/图标直观标识（高=红色、中=黄色、低=绿色）
4. 未设置描述时显示「暂无描述」提示
5. 未设置截止日期时显示「未设置截止日期」
6. 已过截止日期的未完成任务，截止日期以红色警示显示

**优先级**: P0

---

### US-06 编辑任务

> **As a** 已登录用户  
> **I want** 修改任务的标题、描述、优先级和截止日期  
> **So that** 当任务信息发生变化时，我可以更新它保持信息准确

**验收标准 (AC)**：
1. 任务详情页有「编辑」按钮，点击进入编辑模式
2. 可修改字段：标题、描述、优先级、截止日期
3. 修改后点击保存，任务信息更新成功
4. 标题为空时保存，提示校验错误
5. 保存成功后自动退出编辑模式，展示更新后的详情
6. updated_at 时间戳自动更新
7. 点击取消则放弃修改，恢复原始内容

**优先级**: P0

---

### US-07 删除任务

> **As a** 已登录用户  
> **I want** 删除不再需要的任务  
> **So that** 我的任务列表保持整洁，只保留有效任务

**验收标准 (AC)**：
1. 任务详情页或列表中有「删除」按钮
2. 点击删除后弹出二次确认对话框，提示「确定删除该任务？此操作不可恢复」
3. 确认删除后任务被永久移除，从列表中消失
4. 取消删除则任务保持不变
5. 删除成功后给出「任务已删除」的提示

**优先级**: P0

---

### US-08 查看任务列表

> **As a** 已登录用户  
> **I want** 在一个列表中看到我的所有任务  
> **So that** 我可以总览所有待办事项，快速了解当前工作状况

**验收标准 (AC)**：
1. 主页面展示当前用户的全部任务列表
2. 每条任务在列表中展示：标题、优先级标识、状态标签、截止日期
3. 默认按创建时间倒序排列（最新的在前）
4. 列表支持分页或无限滚动
5. 列表为空时展示友好的空状态引导：「还没有任务，点击新建开始吧」
6. 加载列表时展示加载指示器

**优先级**: P0

---

### US-09 筛选任务

> **As a** 已登录用户  
> **I want** 按状态和优先级筛选任务  
> **So that** 我可以快速找到特定类型的任务，聚焦当前重点工作

**验收标准 (AC)**：
1. 列表页提供状态筛选控件：全部 / 待办 / 进行中 / 已完成
2. 列表页提供优先级筛选控件：全部 / 高 / 中 / 低
3. 选择筛选条件后列表即时更新，只显示符合条件的任务
4. 多个筛选条件组合使用时为 AND 关系（如：状态=进行中 AND 优先级=高）
5. 筛选条件变更后同步更新 URL 参数，刷新页面后筛选条件保留
6. 筛选无结果时展示「没有符合条件的任务」提示

**优先级**: P0

---

### US-10 排序任务

> **As a** 已登录用户  
> **I want** 按截止日期对任务排序  
> **So that** 我可以优先看到最紧急的任务

**验收标准 (AC)**：
1. 列表页提供排序切换选项：按创建时间 / 按截止日期
2. 支持升序和降序切换
3. 切换排序后列表立即重新排列
4. 默认按创建时间降序排列

**优先级**: P0

## P0 — 任务状态流转

### US-11 切换任务状态

> **As a** 已登录用户  
> **I want** 一键切换任务的状态  
> **So that** 我可以快速更新任务进度，保持任务状态的实时性

**验收标准 (AC)**：
1. 列表中每个任务旁有状态切换按钮或下拉菜单
2. 点击按钮可以快速将状态推进到下一阶段：待办 → 进行中 → 已完成
3. 可以通过下拉菜单选择任意目标状态（包括回退）
4. 「已完成」状态的任务在视觉上有明显区分（如文字划线、灰色背景）
5. 状态变更后即时生效（乐观更新），无需手动刷新页面
6. 可以将「已完成」的任务重开为「待办」或「进行中」

**优先级**: P0

## P0 — 响应式界面

### US-12 桌面端使用

> **As a** 在桌面电脑上使用的用户  
> **I want** 获得舒适的宽屏布局体验  
> **So that** 我可以在大屏幕上高效管理任务

**验收标准 (AC)**：
1. 屏幕宽度 ≥ 1024px 时展示完整侧边栏 + 主内容区布局
2. 侧边栏展示导航菜单（任务列表、仪表盘等）
3. 主内容区充分利用屏幕宽度展示任务列表
4. 所有交互元素间距合理，鼠标操作舒适

**优先级**: P0

---

### US-13 移动端使用

> **As a** 在手机上使用的用户  
> **I want** 获得适配小屏幕的布局  
> **So that** 我可以随时随地管理任务

**验收标准 (AC)**：
1. 屏幕宽度 < 768px 时切换为单列布局
2. 导航栏折叠为汉堡菜单或底部导航栏
3. 按钮尺寸 ≥ 44px × 44px，触摸操作友好
4. 所有功能在移动端均可正常使用
5. 表单输入时自动弹出合适的键盘类型

**优先级**: P0

## P1 — 标签系统

### US-14 创建标签

> **As a** 已登录用户  
> **I want** 创建自定义标签并选择颜色  
> **So that** 我可以用自己的分类体系组织任务

**验收标准 (AC)**：
1. 标签管理入口可创建新标签，输入标签名和选择颜色
2. 标签名在同用户下不允许重复，重复时提示「该标签已存在」
3. 标签名长度 1-50 字符
4. 提供预设颜色供快速选择，也支持自定义 HEX 色值
5. 创建成功后标签出现在标签列表中

**优先级**: P1

---

### US-15 为任务添加标签

> **As a** 已登录用户  
> **I want** 为任务添加一个或多个标签  
> **So that** 我可以对任务进行分类标记

**验收标准 (AC)**：
1. 创建或编辑任务时可以选择已有标签
2. 一个任务最多关联 10 个标签
3. 超出标签数量上限时提示「每个任务最多添加 10 个标签」
4. 可以移除已添加的标签
5. 任务列表和详情中以彩色胶囊样式展示标签

**优先级**: P1

---

### US-16 按标签筛选任务

> **As a** 已登录用户  
> **I want** 点击某个标签查看该分类下的所有任务  
> **So that** 我可以按项目或主题聚焦查看特定类别的任务

**验收标准 (AC)**：
1. 列表筛选区域增加标签筛选维度
2. 选择某个标签后只显示关联该标签的任务
3. 标签筛选可与状态、优先级筛选组合使用
4. 支持选择多个标签（OR 关系）

**优先级**: P1

## P1 — 搜索功能

### US-17 搜索任务

> **As a** 已登录用户且拥有较多任务  
> **I want** 通过关键词搜索任务  
> **So that** 我可以快速定位到目标任务，不用在长列表中翻找

**验收标准 (AC)**：
1. 页面顶部有固定的搜索输入框
2. 输入关键词后 300ms 自动搜索（debounce），无需按回车
3. 搜索范围覆盖任务标题和描述
4. 搜索结果列表中关键词高亮显示
5. 搜索可与筛选条件叠加使用
6. 搜索无结果时展示「未找到匹配的任务」
7. 清空搜索框后恢复展示全部任务（或之前的筛选结果）

**优先级**: P1

---

## P1 — 统计仪表盘

### US-18 查看任务统计

> **As a** 已登录用户  
> **I want** 查看任务数据的可视化统计  
> **So that** 我可以了解整体工作进度和待办概况

**验收标准 (AC)**：
1. 仪表盘页面展示以下数据：
   - 总任务数
   - 各状态任务数（待办 / 进行中 / 已完成）
   - 本周到期任务数
   - 逾期任务数（截止日期已过且未完成）
2. 使用图表（环形图/柱状图）可视化展示状态分布
3. 统计数据与任务列表实时同步，增删改任务后数据自动更新
4. 统计数据仅反映当前用户自己的任务

**优先级**: P1

## P2 — 体验优化

### US-19 拖拽排序

> **As a** 已登录用户  
> **I want** 通过拖拽调整任务在列表中的顺序  
> **So that** 我可以手动排列任务的优先级顺序

**验收标准 (AC)**：
1. 列表中的任务卡片支持鼠标/触摸拖拽
2. 拖拽时有视觉反馈（阴影、占位符）
3. 释放后任务位置更新
4. 排序结果持久化保存，刷新后保持

**优先级**: P2

---

### US-20 批量操作

> **As a** 已登录用户  
> **I want** 多选任务后批量修改状态或删除  
> **So that** 我可以高效处理多个任务，不用逐个操作

**验收标准 (AC)**：
1. 列表中每条任务前有复选框，点击进入多选模式
2. 支持「全选」功能
3. 选中多个任务后展示批量操作栏：批量完成 / 批量删除 / 批量修改状态
4. 批量删除需二次确认，提示「确定删除选中的 N 个任务？」
5. 批量操作完成后展示结果摘要（如「已成功完成 5 个任务」）

**优先级**: P2

---

### US-21 深色模式

> **As a** 已登录用户  
> **I want** 切换到深色主题  
> **So that** 在夜间或低光环境下使用时减少眼睛疲劳

**验收标准 (AC)**：
1. 设置中有主题切换选项：浅色 / 深色 / 跟随系统
2. 默认「跟随系统」，自动匹配操作系统主题偏好
3. 切换主题后界面颜色立即变化，无页面闪烁
4. 深色模式下所有文字对比度满足 WCAG AA 标准（4.5:1）
5. 用户的主题偏好持久化保存

**优先级**: P2
