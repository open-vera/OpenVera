# 财务报表分析

## 职责

分析师对三大财务报表进行深度解读，计算关键指标并识别趋势。

## 参与角色

- **analyst**: 主导财务分析、指标计算、异常识别
- **researcher**: 补充背景信息，协助解释异常数据

## 输入

- 基础信息产物: [flows/info-gathering/output/](../info-gathering/output/)

## 交付产物（写入报告目录）

写入 `../report/analysis/`：

- `financial-metrics.md` — 关键财务指标（盈利能力、运营能力、偿债能力、成长能力）
- `trend-analysis.md` — 趋势分析（各指标多年变化趋势、异常波动解读）
- `cashflow-quality.md` — 现金流质量分析（经营/投资/融资活动、自由现金流）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（核心发现、财务健康度评估、给行业对标的重点关注项）

## 准出标准

- 覆盖盈利能力（ROE、ROA、毛利率、净利率）
- 覆盖运营能力（存货周转、应收账款周转、资产周转）
- 覆盖偿债能力（资产负债率、流动比率、利息保障倍数）
- 覆盖成长能力（收入增速、利润增速、研发投入比）
- 识别财务异常信号（应收款异常增长、商誉减值风险等）
- 最低得分: 0.85
