# 投资研究报告

## 职责

分析师和风险官共同撰写完整的投资研究报告，给出投资建议。

## 参与角色

- **analyst**: 主导报告撰写、估值建模、投资建议
- **risk-officer**: 审核风险部分，确保风险充分披露

## 输入

- 风险评估产物: [flows/risk-assessment/output/](../risk-assessment/output/)

## 交付产物（写入报告目录）

写入 `../report/`：

- `research-report.md` — 完整投资研究报告
  - 投资摘要（评级、目标价、核心逻辑）
  - 公司概况
  - 财务分析
  - 竞争分析
  - 估值分析（DCF + 相对估值）
  - 风险提示
  - 财务数据附表

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（报告结论、投资评级依据）

## 准出标准

- 投资建议明确（买入/增持/中性/减持/卖出）
- 12 个月目标价有明确的估值依据
- 核心投资逻辑不少于 3 条
- 风险提示充分（不少于 5 条风险）
- 报告结构完整、数据前后一致
- 最低得分: 0.85
