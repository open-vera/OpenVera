# 风险评估

## 职责

风险官和分析师共同识别和量化投资风险，建立风险矩阵。

## 参与角色

- **risk-officer**: 主导风险识别、压力测试、风险评级
- **analyst**: 提供财务数据支撑，协助量化风险影响

## 输入

- 行业对标研究产物: [flows/industry-benchmark/output/](../industry-benchmark/output/)

## 交付产物（写入报告目录）

写入 `../report/analysis/`：

- `risk-matrix.md` — 风险矩阵（风险类型、发生概率、影响程度、应对措施）
- `stress-test.md` — 压力测试（悲观/中性/乐观情景下的财务预测）
- `red-flags.md` — 重大风险预警（需特别关注的高优先级风险）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（综合风险等级、主要风险项、给投研报告的建议）

## 准出标准

- 覆盖经营、财务、市场、合规、治理五类风险
- 每类风险有概率和影响程度双维度评估
- 至少包含三种情景的盈利预测（含关键假设）
- 重大风险有量化估算或明确的定性判断
- 最低得分: 0.8
