# 行业对标研究

## 职责

分析师和研究员通过与行业同类公司对比，评估目标公司的竞争地位。

## 参与角色

- **analyst**: 主导对标分析、竞争优势评估
- **researcher**: 收集竞品数据、行业平均水平

## 输入

- 财务报表分析产物: [flows/financial-analysis/output/](../financial-analysis/output/)

## 交付产物（写入报告目录）

写入 `../report/analysis/`：

- `peer-comparison.md` — 同业对比表（与 3-5 家可比公司的关键指标对比）
- `competitive-position.md` — 竞争地位评估（市场份额、差异化优势、护城河分析）
- `industry-outlook.md` — 行业前景（行业规模、增长趋势、政策影响）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（对标结论、公司相对优劣势、给风险评估的重点）

## 准出标准

- 选取 3-5 家代表性可比公司
- 关键财务指标横向对比完整
- 对目标公司相对竞争地位有明确判断
- 行业景气度有判断（上行/稳定/下行）
- 最低得分: 0.75
