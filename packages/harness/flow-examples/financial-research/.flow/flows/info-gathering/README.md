# 基础信息收集

## 职责

研究员收集上市公司的公开信息，建立基础研究档案。

## 参与角色

- **researcher**: 主导信息收集和数据整理

## 输入

- 研究目标: [goal.md](../../task/goal.md)

## 交付产物（写入报告目录）

写入 `../report/data/`：

- `company-profile.md` — 公司概况（主营业务、发展历程、股权结构、管理层）
- `financials-raw.md` — 原始财务数据（近 3-5 年三大报表关键数据）
- `announcements.md` — 重要公告摘要（并购、融资、战略变化、重大合同）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（数据来源、覆盖范围、数据缺口说明）

## 准出标准

- 覆盖近 3 年完整年报数据（或最新 4 个季度）
- 股权结构清晰（含实控人、主要股东持股比例）
- 识别并标注数据异常或缺失项
- 信息来源可追溯（标注数据来源和时间）
- 最低得分: 0.8
