# 行程规划

## 职责

规划师根据调研结果制定详细的每日行程安排。

## 参与角色

- **planner**: 主导行程设计，平衡游览密度与体验质量

## 输入

- 目的地调研产物: [flows/research/output/](../research/output/)

## 交付产物（写入旅行目录）

写入 `../trip/`：

- `itinerary.md` — 详细行程（按天展开，每天含景点、用餐、交通安排）
- `map-notes.md` — 地图标注说明（各区域景点分布、动线建议）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（行程亮点、设计思路、给预算分析的注意事项）

## 准出标准

- 覆盖 goal.md 中指定的旅行天数
- 每天行程饱满但不过度疲惫（每天景点 2-4 个为宜）
- 地理动线合理，减少不必要的折返
- 含餐饮推荐（含素食/清真/儿童友好等特殊需求处理）
- 含备选方案（雨天方案、体力不支的替代选项）
- 最低得分: 0.8
