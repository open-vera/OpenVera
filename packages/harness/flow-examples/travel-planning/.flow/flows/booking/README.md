# 预订安排

## 职责

规划师根据确定的行程和预算，整理需预订的项目清单和预订建议。

## 参与角色

- **planner**: 整理预订清单、预订建议和时间节点

## 输入

- 预算估算产物: [flows/budget/output/](../budget/output/)

## 交付产物（写入旅行目录）

写入 `../trip/`：

- `booking-list.md` — 预订清单（机票、酒店、景点门票、特殊体验、租车等）
- `booking-guide.md` — 预订指南（推荐渠道、注意事项、取消政策、最佳预订时间）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（预订要点、时间建议、给旅行手册的注意事项）

## 准出标准

- 覆盖行程中所有需提前预订的项目
- 每个预订项标注优先级（必须提前/建议提前/现场可订）
- 含预订截止建议时间
- 含备选方案（主选无法预订时的替代）
- 最低得分: 0.75
