# 目的地调研

## 职责

研究员和规划师共同收集目的地的全面信息，为后续行程规划提供依据。

## 参与角色

- **researcher**: 主导信息收集、整理目的地资料
- **planner**: 评估信息完整性，补充规划视角的需求

## 输入

- 旅行目标: [goal.md](../../task/goal.md)

## 交付产物（写入旅行目录）

写入 `../trip/research/`：

- `destination.md` — 目的地概览（地理、气候、文化、最佳旅行季节）
- `attractions.md` — 景点清单（名称、类型、建议游览时长、门票信息）
- `practical-info.md` — 实用信息（签证、货币、交通、语言、安全提示）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（调研发现、重要提示、给行程规划的建议）

## 准出标准

- 覆盖 goal.md 中指定的目的地
- 至少包含 10 个景点推荐，含分类标注（自然/文化/美食/购物）
- 实用信息完整（签证要求、汇率参考、主要交通方式）
- 识别旅行风险和注意事项
- 最低得分: 0.75
