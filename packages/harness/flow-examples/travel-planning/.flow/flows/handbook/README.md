# 旅行手册

## 职责

规划师和研究员共同整合所有信息，输出一份完整的旅行参考手册。

## 参与角色

- **planner**: 整合行程、预订、预算信息，组织手册结构
- **researcher**: 补充实用信息、应急联系方式、当地文化提示

## 输入

- 预订安排产物: [flows/booking/output/](../booking/output/)

## 交付产物（写入旅行目录）

写入 `../trip/`：

- `handbook.md` — 旅行手册（行程总览、每日安排、实用信息、应急联系）
- `checklist.md` — 行前准备清单（证件、物品、App、注意事项）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（手册完整性评估、特别提示）

## 准出标准

- 手册包含完整行程（每天时间表）
- 实用信息完整（应急电话、大使馆、医院、当地 SIM 卡）
- 行前清单覆盖签证、保险、换汇、物品准备
- 手册可直接打印/导出使用，无需二次查找信息
- 最低得分: 0.85
