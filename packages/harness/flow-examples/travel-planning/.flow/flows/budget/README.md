# 预算估算

## 职责

预算分析师和规划师共同制定费用估算和预算控制方案。

## 参与角色

- **budget-analyst**: 主导费用估算、预算分配和节省建议
- **planner**: 提供行程细节，协助确认费用项目

## 输入

- 行程规划产物: [flows/itinerary/output/](../itinerary/output/)

## 交付产物（写入旅行目录）

写入 `../trip/`：

- `budget.md` — 预算表（分项明细：机票、住宿、餐饮、景点、交通、购物、应急）
- `saving-tips.md` — 省钱攻略（优惠时间、折扣渠道、可省项目）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（预算总额、主要费用分布、给预订的注意事项）

## 准出标准

- 涵盖所有费用项目（无遗漏主要开销）
- 每项费用有估算依据（参考来源或计算方式）
- 设置应急备用金（建议总预算 10-15%）
- 提供高/中/低三档预算方案
- 最低得分: 0.75
