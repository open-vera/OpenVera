# 数据预处理

## 职责

数据管理员对原始数据进行清洗、去重和格式标准化，为标注做准备。

## 参与角色

- **data-manager**: 主导数据清洗、格式转换、任务分配

## 输入

- 标注规范产物: [flows/spec/output/](../spec/output/)

## 交付产物（写入数据集目录）

写入 `../dataset/`：

- `raw/` — 原始数据备份（不可修改）
- `processed/` — 清洗后数据（标准化格式，待标注）
- `data-report.md` — 数据质量报告（总量、清洗情况、数据分布统计）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（数据规模、清洗情况、分布统计、给标注的注意事项）

## 准出标准

- 原始数据完整备份且不被修改
- 清洗后数据格式符合规范要求
- 数据去重完成，无重复样本
- 数据分布统计完整（文本长度、类别分布等）
- 异常数据有标注（过短/过长/含特殊字符/语言不符）
- 最低得分: 0.8
