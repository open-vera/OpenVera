# 质量检验

## 职责

质检员对标注结果进行抽样复核，计算质量指标，输出质检报告。

## 参与角色

- **qa-inspector**: 主导质检抽样、复核评分、报告输出
- **annotator**: 接收反馈，对不合格项进行修正

## 输入

- 内容标注产物: [flows/annotation/output/](../annotation/output/)

## 交付产物（写入数据集目录）

写入 `../dataset/qa/`：

- `qa-report.md` — 质检报告（抽样比例、错误率、错误类型分布、改进建议）
- `corrections.jsonl` — 修正记录（质检中发现并修正的错误条目）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（质检结论、是否通过、遗留问题、给交付的注意事项）

## 准出标准

- 抽检比例 ≥ 10%（或按 goal.md 中要求）
- 标注准确率 ≥ 90%（或按 goal.md 中要求）
- 错误类型分类统计完整
- 不合格批次已触发返工（标注员修正并重新提交）
- 修正记录完整可追溯
- 最低得分: 0.85
