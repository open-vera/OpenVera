# 标注规范制定

## 职责

数据管理员和标注员共同制定标注规范，确保标注任务可执行且一致。

## 参与角色

- **data-manager**: 梳理标注任务目标、数据说明、交付格式
- **annotator**: 从执行视角评估规范的可操作性，提出边界案例处理建议

## 输入

- 任务目标: [goal.md](../../task/goal.md)

## 交付产物（写入数据集目录）

写入 `../dataset/spec/`：

- `annotation-guideline.md` — 标注指南（任务说明、标签体系、标注规则、示例）
- `edge-cases.md` — 边界案例处理手册（歧义情况、特殊格式、缺失信息处理规则）
- `output-format.md` — 输出格式规范（字段定义、数据格式、示例 JSON/CSV）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（规范要点、主要决策说明、给预处理的注意事项）

## 准出标准

- 标签体系完整，覆盖 goal.md 中全部标注类型
- 每个标签有清晰定义和正/负例
- 边界案例有明确处理规则
- 输出格式有完整字段说明和示例
- 最低得分: 0.85
