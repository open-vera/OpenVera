# 数据交付

## 职责

数据管理员和质检员共同完成数据集打包、版本归档和交付。

## 参与角色

- **data-manager**: 主导数据打包、格式转换、版本管理
- **qa-inspector**: 确认最终数据质量，签核交付

## 输入

- 质量检验产物: [flows/qa/output/](../qa/output/)

## 交付产物（写入数据集目录）

写入 `../dataset/delivery/`：

- `dataset-v{N}.zip` — 最终数据集压缩包
- `dataset-card.md` — 数据集说明卡片（规模、标签分布、质量指标、使用说明）
- `changelog.md` — 变更记录（各版本差异、修正内容）

## 步骤记录（写入 output/）

写入本目录 `output/`：

- `summary.md` — 执行摘要（交付内容确认、质量指标汇总、使用注意事项）

## 准出标准

- 数据集包含全部通过质检的标注数据
- dataset-card.md 包含完整统计信息（总量、各标签数量、准确率）
- 数据格式符合交付方要求
- changelog.md 记录完整
- 压缩包可完整解压，文件无损坏
- 最低得分: 0.9
